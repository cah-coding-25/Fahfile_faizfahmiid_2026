# Android to Desktop File Manager 📂🔗

Aplikasi pengelola file berbasis Android yang memungkinkan Anda menghubungkan ponsel pintar ke Laptop atau PC secara nirkabel melalui jaringan Wi-Fi lokal yang sama. Cukup via browser, tanpa perlu kabel USB atau koneksi internet (kuota data).

**Author:** `faiz_fahmi_id`

---

## 🌟 Manfaat Aplikasi (Benefits)
1. **Tanpa Kabel (Wireless):** Memindahkan file dari Android ke PC atau sebaliknya tanpa repot mencari kabel data atau *flashdisk*.
2. **Tanpa Kuota Internet:** Karena menggunakan jaringan Wi-Fi lokal yang sama (LAN/Hotspot), proses transfer tidak memakan kuota data internet sama sekali.
3. **Kecepatan Tinggi:** Kecepatan transfer bergantung pada kestabilan sinyal Wi-Fi lokal (bisa mencapai kecepatan router lokal yang optimal).
4. **Lintas Platform (Cross-Platform):** Tidak memerlukan instalasi software khusus di PC/Laptop; cukup menggunakan browser web standar (Chrome, Firefox, Edge, Safari, dll).
5. **Manajemen File Fleksibel:** Tampilan antarmuka berbasis web membuat pengelolaan file di HP terasa seperti mengelola file di komputer.

---

## 💡 Solusi yang Diberikan (Solutions)
* **Solusi Perangkat Tanpa Port / Kabel Rusak:** Memudahkan pengguna yang mengalami kendala pada port USB perangkat atau tidak membawa kabel data.
* **Solusi Transfer File Berukuran Besar:** Memindahkan video, foto, atau dokumen berukuran besar dalam waktu singkat langsung dari penyimpanan internal Android ke layar PC yang lebih besar.
* **Solusi Kemudahan Akses:** Pengguna dapat langsung melihat, mengunduh, mengunggah, dan menghapus file HP langsung dari browser komputer dengan antarmuka yang intuitif.

## 🛠️ Penjelasan Fitur Lengkap (Feature Breakdown)

Berdasarkan antarmuka aplikasi (*Hubungkan ke Desktop*), berikut adalah rincian fitur yang tersedia:

### 1. Tombol **Mulai Server**
* **Fungsi Utama:** Menghidupkan layanan server HTTP lokal di dalam perangkat Android. 
* **Cara Kerja:** Ketika tombol ini ditekan, aplikasi akan menghasilkan sebuah tautan (URL) unik (misalnya `http://192.168.1.5:8080`) yang kemudian diketikkan pada browser laptop/desktop.

### 2. Panduan Jaringan Wi-Fi
* **Fungsi:** Memberikan informasi pengingat kepada pengguna agar memastikan perangkat Android dan laptop/desktop terhubung ke **jaringan Wi-Fi yang sama** agar koneksi lokal berhasil terjalin.

### 3. Folder yang Dibagikan (*Shared Folder*)
* **Fungsi:** Menentukan direktori atau folder penyimpanan spesifik di Android yang dapat diakses oleh PC.
* **Fitur Ubah:** Pengguna dapat menekan tombol **"Ubah"** untuk memilih folder tertentu saja (misalnya folder `Download` atau `DCIM`) demi menjaga privasi folder sistem lainnya, dengan *default* awal berada di akar penyimpanan (`/storage/emulated/0`).

### 4. PIN Keamanan Lokal (*Local Security PIN*)
* **Fungsi:** Fitur keamanan tambahan untuk mencegah perangkat lain di jaringan Wi-Fi yang sama mengakses file Anda tanpa izin.
* **Cara Kerja:** Jika diaktifkan, browser desktop wajib memasukkan PIN yang benar sebelum dapat menampilkan isi file ponsel.

### 5. Enkripsi TLS (HTTPS)
* **Fungsi:** Meningkatkan privasi dan keamanan tingkat lanjut pada proses pengiriman data.
* **Cara Kerja:** Mengubah protokol transfer dari standar HTTP biasa menjadi HTTPS dengan opsi port tertentu (misalnya port 8080), sehingga data yang ditransfer terenkripsi dengan aman.

### 6. Log Aktivitas Server (*Server Activity Log*)
* **Fungsi:** Memantau riwayat aktivitas atau interaksi yang terjadi pada server lokal.
* **Indikator:** Menampilkan jumlah aktivitas (misalnya `Lihat (0)`) untuk melacak perangkat mana saja yang terhubung atau mengunduh file dari ponsel Anda.

## 🚀 Cara Penggunaan Singkat
1. Hubungkan Android dan Laptop ke jaringan Wi-Fi yang sama.
2. Buka aplikasi dan atur folder yang ingin dibagikan.
3. Tekan tombol **Mulai Server**.
4. Ketik alamat URL yang muncul ke browser di laptop Anda.
5. Kelola, unduh, atau unggah file dengan mudah!
